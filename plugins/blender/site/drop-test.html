Drop a .bn into Blender

A manual test of the Base Node add-on's drop of a .bn file. The sample, drop_example.bn, offers in its head what it can do: // @offer library, groups, example, modifier.

The four drag sources

1Download linkA plain link with download: click it, or drag it.
2DownloadURLdragstart sets DownloadURL (Chrome, Edge): the browser writes the file where it is dropped.
3text/uri-listdragstart sets the https URL of the file.
4text/plaindragstart sets the file's text.

Result

None of them gives Blender a file, on Linux (Wayland and X11), Windows or macOS: Blender reads a dropped file only from disk (file://, CF_HDROP, a file URL). Chrome's DownloadURL is a virtual file it does not read, it keeps only the file:// URIs of a text/uri-list, and a text is a string no add-on can catch. So <bn-view> and <bn-file> download the .bn, for File > Import or a drop from the file manager.

Protocol

Serve this folder over http(s), not file:// (the page reads the sample with fetch, and Chrome's DownloadURL needs a URL it can fetch): python3 -m http.server -d site 8000, then open http://localhost:8000/drop-test.html, or the GitHub Pages copy. In Blender 5.3, with the add-on enabled and a Module Folder set in its preferences, start from the default scene (the Cube selected).

Drag each source onto each target. For every drop, note:

  • Received? Did Blender get a file (the dialog Ripples and waves opens), a string (nothing, or Blender's own handling of a text or a link), or nothing at all?
  • Dialog: author Base Node, license MIT; the four choices; which one is chosen first; what Add as Modifier says it will be applied to.
  • Result after Open, for one choice per drop (see the last column).

Which source gives Blender a file depends on the browser, the OS and the desktop: that is what this test finds out. A downloaded file, dropped from the file manager, is the reference case. text/uri-list and text/plain are expected to reach Blender as strings, which only Blender's own C drop handlers see: the add-on cannot act on them, and downloads nothing. Write down what actually happens, with the browser, its version, the OS and the desktop.
