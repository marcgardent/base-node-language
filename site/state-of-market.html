Node to Text and Text to Node, in Blender

The direct competitors. Node to Text writes an existing node tree as text; Text to Node builds a node tree from text. Most tools do the first, and read back only their own output: a serialization (JSON, XML, a hash) or Python to run. None is hand-writable: a format made for a person to write a graph from scratch in a text editor, read it and change it. None has syntactic sugar (pipes, expressions written as formulas), generic templates (a graph written once for every type) or a standard library. Only BNDL Pro is sold, at $29.

Positioning

No other tool offers readable text that round-trips with nodes across all three domains, backed by a standard library tested against third-party corpora. The closest are VEX (tied to Houdini), Nuke's .nk (compositing only) and, in Blender, serializers such as Node Runner and BNDL or Python generators such as NodeToPython, none of them meant to be written by hand. In short: what Houdini, Nuke and Substance do, as versionable text inside Blender, and out of it through MaterialX.
