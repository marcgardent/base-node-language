Base Node Language

Base Node (.bn) is a text format for node graphs: a graph is a function, a node a call. Its core reads a text into a syntax tree, prints it and formats it, in Python and in Rust. The core knows no destination: a host library says what a kind of tree, a type or a node means, and checks a text against it.

use math (bump)

geometry graph relief(geometry: Geometry, height: Float = 0.4 in 0.0..2.0) -> Geometry {
  "Displaces vertices along Z using a radial bump"
  h = bump(length(Position()) / 3.0, 0.5, 0.2) * height
  return SetPosition(geometry, offset: CombineXYZ(z: h))
}

Libraries

  • Python: the package base-node (base_node, and the command line base-node), no dependency, Python 3.10 or later
  • Rust: the crate base-node, wasm32-compatible

conformance/: .bn cases and their expected syntax trees, read by the Python and the Rust tests alike.
