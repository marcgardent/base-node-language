Blender node trees, written as text.

Geometry Nodes, shaders, the compositor and Grease Pencil as .bn files you can read, diff, review in git, paste into Blender and generate. The add-on turns the text into nodes while you type, and the nodes back into text. Open source (MIT or Apache-2.0), with a standard library, parsers in Python and Rust, and a web viewer.

Install and use it in Blender

One-click install via Blender Remote Extension Repository:

https://basenode.ludopant.com/extensions/index.json

In Blender: Edit > Preferences > Get Extensions > Repositories > + > Add Remote Repository, paste the URL above, and install Base Node.

Blender 5.2+ extension (id = "base_node"). The node tree is the only data: its .bn text is a temporary view of it.

  • Alt+Z in the Node Editor shows the edited tree as .bn text in the same area; in the Text Editor, it writes the text back into the tree and returns to the nodes.
  • The tree follows the text: once it is valid, it is built into the tree by itself (Apply while typing, in the preferences or the sidebar); Alt+P applies it without leaving the text; Ctrl+Space opens suggestions.
  • File > Import > Base Node (.bn) builds the graphs of one or more .bn files.
  • Shader and compositor trees are written as shader graph and compositor graph. They can call a module's graphs: use math (gain) in a compositor graph builds gain again in a compositor group, gain (Compositor).
  • A use math finds math.bn in the .blend's texts, next to the imported file, in the Module Folder of the preferences, then in the standard library bundled with the add-on.

Copy and paste graphs as text

  • Ctrl+Shift+C in the Node Editor (Node > Copy as .bn, sidebar Text) puts the edited tree on the clipboard as .bn text, with the groups it calls: it builds on its own in another file. Only the standard library stays a use, since every file finds it. Copy Selected as .bn copies only the selected nodes, as a graph of their own.
  • Ctrl+Shift+V (Node > Paste .bn) builds the .bn text of the clipboard into the current file and shows it. A text with an error changes nothing, and the status bar gives its line; a graph of the name of an existing group rebuilds it in place (Ctrl+Z undoes it).
  • Ctrl+C / Ctrl+V still copy and paste nodes; on macOS the keys are Cmd+Shift+C / V.

Copy this, press Ctrl+Shift+V in a Geometry Node editor, then Add as Modifier: columns on a grid rise with a ripple from the centre (examples/ripples.bn). 

use math (palette, sine01)

geometry graph ripples(count: Int = 40 in 2.., waves: Float = 2.5, height: Float = 0.6) -> Geometry {
  "Columns on a grid that rise with a ripple from the centre, coloured by their height"
  p = Position()
  rise = sine01(length(CombineXYZ(p.x, p.y)) * waves * 0.5) * height + 0.05
  column = Cube(size: (0.08, 0.08, 1.0)) |> TransformGeometry(translation: (0.0, 0.0, 0.5))
  return Grid(4.0, 4.0, count, count)
    |> MeshToPoints()
    |> InstanceOnPoints(instance: column, scale: CombineXYZ(1.0, 1.0, rise))
    |> RealizeInstances()
    |> StoreNamedAttribute(name: "color", value: palette(Position().z / height), data_type: FLOAT_COLOR)
}

The free standard library

Eleven modules ship with the add-on: 2D SDFs and curves, fillets, planar maps, patterns, math and noise, compositor masks, Nuke-style merges and grades, STMaps and QC charts. Their graphs, targets and pictures are on the Developers page, every graph in the Reference.

Other tools that write nodes as text

Nuke, Houdini, Substance Designer, MaterialX, ComfyUI, Unity, Godot, Unreal and TouchDesigner each store or script their node graphs in their own way. State of the Art — Autumn 2026 compares which ones read their text back, with sources.
